# 기출 지우개 · 듣기 오디오

[기출 지우개](https://jjangguss-prog.github.io/gichul-jiugae/) 앱에서 '🔊 듣기'를 누르면 재생되는 파일입니다.

- `patterns/`: 공인중개사 1차 기출 패턴 45개(민법 25, 학개론 20). 패턴 이름 → 결론 → 풀어 쓴 문장 → 표 → 기출로 확인.
- `tsx/`: 타시험 예상 논점 카드(민법 34, 학개론 33). 형광펜 자리를 '빈칸'으로 읽고 → 잠깐 쉬고 → 온전한 문장 → 틀린 꼴.
- `rep/`: 또 나온 문장(10년 동안 3회 이상 나온 지문). 지문 → 잠깐 쉬고 → 맞는 말 / 틀린 말·바르게는 → 해설.
- `memo/`: 개념서 장마다 A·B급 섹션의 외우기 한 줄.
- 목소리: 저장소 주인 본인의 목소리를 AI(VoxCPM2)로 합성한 것입니다.
- 이 목소리를 다른 콘텐츠나 음성 합성 학습 등 다른 용도로 쓰지 마세요.

`audio.json`이 묶음(patterns·tsx·rep·memo)과 id별 파일·길이·부분 시작 초를 알려 주고, 앱은 이 목록에 있는 것만 듣기 버튼을 띄웁니다.
이 저장소를 지우면 앱의 듣기 버튼만 사라지고 나머지는 그대로 동작합니다.
