# 기출 지우개 · 패턴 듣기 오디오

[기출 지우개](https://jjangguss-prog.github.io/gichul-jiugae/) 앱의 ★패턴 화면에서 '듣기'를 누르면 재생되는 파일입니다.

- 내용: 공인중개사 1차 기출 패턴 45개(민법 25, 학개론 20). 패턴 이름 → 결론 → 풀어 쓴 문장 순서로 읽습니다.
- 목소리: 저장소 주인 본인의 목소리를 AI(VoxCPM2)로 합성한 것입니다.
- 이 목소리를 다른 콘텐츠나 음성 합성 학습 등 다른 용도로 쓰지 마세요.

`audio.json`이 패턴 id별 파일과 길이를 알려 주고, 앱은 이 목록에 있는 패턴만 듣기 버튼을 띄웁니다.
이 저장소를 지우면 앱의 듣기 버튼만 사라지고 나머지는 그대로 동작합니다.
